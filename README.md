# SPELL-SCRIPT
A Harry Potter Inspired Programming Language. 

HTML and CSS was inspired from online sources. Have used AI to create the js alone. Python files were fully written by me without any external source help or AI.

Spell is a syntax used to display or print anyhting the wizard wants.(No need for any strings, whatever you give after spell is displayed after stripping blank spaces.)
Eg: Spell HelloWorld
The output will be:
HelloWorld
